Desktop Applications (lila desktop)

Because Lila v2.0 uses SQLite Async (WAL mode), in-memory caching, and View Transitions SPA routing, any web application built with Lila can be executed and bundled as a standalone desktop program consuming 10x less RAM than Electron (~20MB RAM vs ~200MB).

1. Running in Desktop Mode

Launch a native desktop window in one command:

# Starts Uvicorn in a daemon thread and opens a native window
lila desktop dev

# Custom options:
lila desktop dev --title "My Desktop App" --width 1280 --height 850
💡 Dual Window Engine:
  • Preferred (pywebview): Uses Microsoft WebView2 on Windows, WebKit on macOS, and WebKitGTK on Linux. Install with: pip install pywebview
  • Fallback (Zero-Dependency): If pywebview is not installed, Lila detects Edge, Chrome, or Brave and launches in isolated standalone --app window mode without toolbars.

2. Compiling Standalone Executables (.exe / Binary)

Bundle your entire Lila backend, SQLite database, static assets, and templates into a single standalone binary using PyInstaller: 

# Install packaging dependencies:
pip install pyinstaller pywebview

# Build single-file executable:
lila desktop build --name "InvoiceManager" --onefile --windowed

# The compiled binary is ready in dist/InvoiceManager.exe!

3. Packaging Assets and PyInstaller sys._MEIPASS

Lila's lila.core.config automatically resolves template paths and static asset directories respecting PyInstaller's temporary unpack directory (sys._MEIPASS), while ensuring your SQLite database file and log directories are created in the user's active folder.
