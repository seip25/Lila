Zero-Infrastructure & AI-First Architecture

Lila v2.0 is engineered for the 95% of real-world projects that want high performance without devops bloat. Run SQLite in WAL mode with In-Memory LRU cache by default, and scale optionally to Redis or PostgreSQL whenever needed.

⚡

SPA View Transitions Runtime

Zero build-step client (lila-client.js) intercepts links, prefetches on hover, and transitions views smoothly with native browser APIs.

* Pure ASGI stack on Starlette + Pydantic v2 + SQLAlchemy 2.0 Async.

bash
$ pip install lila-framework
$ lila init
$ lila dev # Hot-reload web server
$ lila desktop dev # Native desktop window
$ lila desktop build # Compile .exe binary
